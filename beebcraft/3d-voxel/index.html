BEEBCRAFT 3D

Stage 3 - true voxel engine (experimental). A 16x16x8 block world rendered in real 3D (every run of voxels in every column, with per-pixel occlusion): overhanging roofs, arches, tree canopies and tunnels; dig and build any block in 3D. Runs at about 3-7 frames per second. Pure 6502 on a 32K BBC Micro Model B in MODE 7, running in jsbeeb (BBC B, DFS 1.2), auto-booted with SHIFT+BREAK. Click the emulator to give it the keyboard.

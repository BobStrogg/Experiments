BEEBCRAFT

A side-on Minecraft-like sandbox in pure 6502 machine code for the BBC Micro Model B, in MODE 7 teletext. Running in jsbeeb (BBC B, DFS 1.2), auto-booted with SHIFT+BREAK. Click the emulator to give it the keyboard.
Z / Xwalk left / right (auto step-up)
SPACE or :jump / swim up
Cursor keysaim the target cursor (up to 2 tiles away)
RETURNmine the target block
/place the selected block
1-9, 0select hotbar slot
Ccolour / monochrome
Ttile style: ASCII / SHADED / BLOCK / MIXED
Gcontiguous / separated graphics
Nnew world
Q / ESCAPEquit to BASIC
Open in the full jsbeeb UI · Download beebcraft.ssd

On a PC keyboard jsbeeb maps keys by position; the BBC's : is next to L and / is next to the right-hand Shift. Cursor keys are the arrow keys.
